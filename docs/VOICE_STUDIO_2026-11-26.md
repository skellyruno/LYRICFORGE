# Voice Studio, demonstrator and motion update

- Four fact-grounded script formats (tutorial, review, advertisement, documentary). This is a deterministic local writer, not an LLM; external agents may supply their own scripts.
- Narration delivery profiles adjust pacing, phrase/chapter pauses and basic-draft pitch. They are not emotional neural acting. Pronunciation replacements affect only spoken text, never caption spelling. Piper is optional; the actual model must be installed and licensed by the operator.
- Voice Studio can import a recording or request microphone capture via browser/WebView2 APIs. Up to ten minutes per microphone take; imported audio up to thirty minutes. Source bytes retained. Optional chapter timestamps map the script to the take; word timing remains estimated and must be reviewed. Audio level and clipping checks, silence rejection. No automatic voice cloning. Native capture permissions and real microphone use remain to be tested on Windows.
- Agent CLI: `python studio_cli.py create job.json --out finished/video`, with `voice: recorded`, `recording: voice.wav`, exact `chapters`, optional `chapter_starts: [0, 12.5, ...]`. Synthesized voices accept `delivery` and `pronunciation` mapping. `title_style` supports adaptive, slide, fade and pop. `story` supports four formats.
- Agent CLI: `python studio_cli.py compare dry.wav wet.wav --out finished/compare --title "My plugin" --label-before DRY --label-after WET --step 4 --rounds 2 --start 1`. Repeat/toggle, optional `--no-match`, output video + source hashes and settings. Operator must verify source identity, latency and alignment. Existing A/B renderer now uses full-intensity waveform colors (fixes FFmpeg accumulation color wrap).
- Real demonstration uses the same synthetic source and actual SkellyTune Mini META 0 ms CI output, artifact 15110475665 from run 45806415896 (035f381); no private vocal recordings committed. The 16-second render has equal video/audio stream duration. The level-matched result uses RMS matching (reported gain rounded to 0 dB); not a subjective or real-singer quality evaluation. This is not a continuous recording of plugin knob movement.
- Piper engine is GPL-3.0-or-later and model licenses differ. See https://github.com/OHF-Voice/piper1-gpl/blob/main/docs/LICENSING.md and COMMERCIAL_USE.md. Do not default to lessac-derived voices for commercial videos. The optional neural provider has not been tested in the offline local runtime.
