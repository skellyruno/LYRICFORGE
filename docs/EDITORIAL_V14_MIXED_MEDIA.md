# SkellyMotion V14 — mixed-media cinema

Continuation of V13 local source candidate. No release/main changes, no original source archives overwritten. No private/reference footage, captured UI, model weights, licensed sound bank, or generated film bundled in the source ZIP.

## Rendering
- `studio_media_layers.py`: image/document/footage layers reference existing 32-character project-local asset IDs. No paths, URLs, or remote loading. Image orientation respected; contain/cover policies are explicit. Video strips have an independent 30 FPS source clock, explicit start/end and optional delay, 20-second maximum per strip; three per composition, six per connected transition. Bounded temporary disk decode, hold last available source frame, no automatic reversal, loop, or source-audio mix. 60 FPS output is not motion-interpolated source footage. Cache keys contain file size and mtime for current and outgoing media; disabled and linked assets rejected. Media and previous composition share a bounded temporary bank; it is cleaned on exit. Texture maps use bilinear UV sampling, perspective ray/sphere intersections and two approximate lights. Cast shadow is an analytic composited ellipse; not a full 3D scene, global illumination, arbitrary mesh importer, or ray-traced volumetric renderer.
- `studio_layers.py`: new media primitives and serif/mono/sans text with left/center alignment, glyph fitting, independent transforms and depth ordering. Original V13 layer primitives preserved. Connected transitions keep shared compatible layer identities; footage uses explicit shot-local trims and does not silently retime. A new Creator request can reference uploaded files by zero-based `upload_index` within a composition media layer; server prevalidates and resolves exact IDs after import, including deduplicated files, then saves canonical script. Existing direct Director compositions use actual `asset` IDs. No new mandatory UI controls.
- `studio_auto_composition.py`: explicitly requested comparison/collage language plus positive metadata match for two supplied B-roll/document assets can produce an automatic composition. Excludes plugin recordings/captured states, disabled and sourced internet imagery. Existing authored graphics win; this is not proof verification or unrestricted autonomous directing.
- `studio_reference_vision.py`: optional configured local CLIP model via existing isolated worker. Selects up to 12 representative/high-change frames, scores role and technique prompts, returns provisional hypotheses and relative margins. Human annotations take precedence. Model results contribute at most a small tie-break for already relevant media; no claims or citations inferred. Set SKELLYMOTION_VISION_MODEL to trusted local CLIP model directory and SKELLYMOTION_AI_PYTHON to configured runtime (transformers, torch, Pillow). No model download, no remote code. Real inference not verified in this environment; model absent and network DNS resolution failed. Tests mock model responses, exercise validation and selection only.
- `studio_quality.py`: pre-publication decoded-frame review (max 240 samples) detects nearly blank/flat shots and high fraction of near-static sampled pairs; checks actual rendered glyph bounds at five times per composition for conservative title safe area and text-text overlap. Findings are warnings, not subjective artistic approval. Decode failure blocks publication. Report persisted in Director plan and returned job stats. Existing frame count/stream gate remains.

## Reproduce original film

Set LYRICFORGE_SOUNDFONT to a trusted local SF2/SF3 bank to enable sampled instruments. Authored educational film on image sampling, with real source-derived pixel measurements, source document, previous SkellyMotion exported B-roll, and an area-averaged 24×12 RGB texture whose display gamma is lifted for illustration. The old production excerpt is explicitly labeled as prior production, not live demonstration. No user reference footage incorporated. Fresh narrative script retained; `--narrate` explicitly requests Kokoro Michael (local model, voices and isolated Python configured via LYRICFORGE_KOKORO_PYTHON, LYRICFORGE_KOKORO_MODEL, LYRICFORGE_KOKORO_VOICES). Chapter boundaries derive from measured phrase timing, including multiple phrases per chapter. No robotic fallback. Real fresh neural synthesis remains blocked because model assets/runtime absent and DNS lookup failed; film intentionally music-led. Film is authored via example and shared engine, not a proof of autonomous full production from a brief.
