## Implemented
- Music-video Director style, 120 BPM synthetic click-grid regression, confidence-based beat cuts, phrase-aware cuts, word-timestamp caption partitioning and overlap repair. Beat analysis uses a bounded 90-second excerpt; longer tracks fall back to timed cuts beyond the analyzed grid. Steady-tempo assumption; variable-tempo accuracy unverified.
- Frame-derived exposure/contrast/detail/saturation, edge-centroid crop focus, perceptual hashes, two sampled video frames for motion estimate. Optional local CLIP relative matching of up to 12 media assets and 64 text snippets, without network; no semantic model bundled.
- Short footage loop extension, varied starting offsets, mirrored/graded/vignetted clips, reverse/ping-pong on short shots, and soft dip-to-black transitions without changing audio duration. Full overlapping xfade transition bank and seamless loop-end blending not implemented.
- Audio-reactive waveform with continuous adjacent visualizer segments (up to 30 seconds), no unnecessary dip between them; real FFmpeg rendering and independent audio mux. Platform output: landscape, 15/30s vertical, square, and 7.5-second muted Canvas where input duration permits; start offset in seconds.
- Conceptual animated compression transfer curve, EQ bell, delay echoes, reverb decay and pitch waveform. These are explanatory illustrations, not plugin-measured plots.
- Optional local Stable Diffusion generation for unfilled visual slots; at most two newly generated pictures per render, cached and labelled as AI illustrations. Existing Commons sourcing stays opt-in. Requires installed trusted local model with safetensors and a safety checker; no download, no secrets, no cloud calls. Model output may be unsuitable and requires review.
- Preflight review checks contiguous frame counts, caption range/overlap, reading speed, very short shots, repeated footage, low beat confidence. Automatically repairs certain caption overlaps and blocks exports with remaining timing errors. Does not prove semantic or visual correctness.

## Optional local AI setup (not mandatory)
Install a separate trusted Python environment with torch, transformers, diffusers, accelerate, Pillow, safetensors. Point `SKELLYMOTION_AI_PYTHON` to that environment's Python executable, `SKELLYMOTION_IMAGE_MODEL` to a compatible local Stable Diffusion directory and `SKELLYMOTION_VISION_MODEL` to a compatible local CLIP directory. No model files or model packages are bundled. The Windows workflow includes `studio_ai_worker.py` as an external worker resource. Missing/failed model leaves local fallback intact. Worker has a timeout; in-progress inference is not immediately interruptible by the render cancel button. Models and external interpreter must be trusted.
