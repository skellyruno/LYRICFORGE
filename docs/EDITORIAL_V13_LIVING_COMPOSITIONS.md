# SkellyMotion V13 — living compositions

Continuation of the preserved V12 local source candidate. All 183 baseline file paths retained. This is a local development candidate, not a new Windows release or GitHub merge. No private audio, reference footage, captures, model weights, or SoundFont bank included.

## Changes
- `studio_layers.py`: bounded authored composition schema with 32 layers, independent normalized keyframe tracks, camera parallax, stable depth ordering, opacity, and deterministic animation. Text, paper evidence, waveforms, discrete samples, measured spectrum, particles, rings, lines, and projected 3D wave mesh. The mesh and particles are educational illustrations, not a fluid simulation. The new low-resolution analytic scattering background and projected floor-shadow approximation also improve spatial product presentations; not full physically based volumetrics or ray tracing.
- Shared layer identities across compatible compositions interpolate their own position/scale/opacity and preserve the global procedural clock. Unmatched objects enter or leave independently. Non-composition transitions retain V12's existing behavior. Original media/capture provenance preserved; recorded demonstrations are not retimed. Composition primitives are authored graphics; arbitrary uploaded-media layers and full scene graph editor are not yet implemented.
- `studio_story.py`: derive storytelling grammar from human-confirmed reference observations and use it as a bounded tie-break for relevant source selection. A local reference CLI manifest can supply `reference_notes` along with `reference`. Existing pacing analysis retained. The supplied three reference studies have 19 observations of hook, context, evidence, comparison, demonstration, explanation and resolution. The labels are human/assistant-reviewed frame annotations, not automated multimodal semantic understanding. No reference footage is copied into output.
- New example `examples/sound_documentary.py`: original music-led 45-second visual educational short, 960x540 at 60fps. Uses actual FFT magnitudes of a 1-second synthetic 440/880/1320Hz signal (1.00/0.50/0.25 normalized). No speech; on-screen text and original sampled-instrument arrangement. A fresh Kokoro model/runtime is not available in this local environment; no draft-voice substitution. Film authored by example script through the existing Director renderer, not autonomously generated from a single brief. To reproduce: set a licensed local `LYRICFORGE_SOUNDFONT` (optional) and run `python examples/sound_documentary.py NEW_OUTPUT_DIR`. The existing Creator interface and plugin music path remain intact.
