## Implemented in this WIP source ZIP

1. `server.py`: Media duration and background dimension readers prefer PyAV and
   fall back to the already-required FFmpeg metadata reader when PyAV is absent.
   FFprobe is *not* a new requirement. Invalid song uploads return HTTP 400
   and clean the partially created project directory. Invalid PyAV container
   errors are now normalized to readable validation failures as well.
2. `studio_edit.py`: Logo replacement writes an RGBA PNG to a private temporary
   file before an atomic replacement. Invalid images cannot delete a valid
   existing logo. Original logo and Brand Kit formats remain unchanged.
3. `server.py`: Read-only Brand Kit checks do not create a `_brand` directory,
   so invalid Animation/Make requests cannot create empty workspace folders.
4. Regression coverage was added to `tests/test_pyav_probing.py` and
   `tests/test_autonomous_api.py`.
